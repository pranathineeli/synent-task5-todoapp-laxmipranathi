# To-Do List Web Application

## Project Overview
This project is a responsive To-Do List Web Application developed as part of the Synent Technologies Web Development Internship Program.

## Features
- Add Tasks
- Delete Tasks
- Mark Tasks as Completed
- Data Persistence using localStorage
- Responsive User Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Objective
To build a functional task management application using JavaScript and browser localStorage.

## Outcome
Enhanced understanding of DOM manipulation, JavaScript functionality, and localStorage implementation.
